## SIGNIFICANT

**1. `.git/` directory exposed in the publish root — FIXED.**
`C:\Users\abdul\shariah-invest-au` is itself a git working copy, and per its own `.gitignore` comment, "this folder is the deployable site... what is committed here is exactly what gets published." That means `.git/` (1.9MB, full commit history) sits inside the directory that gets deployed. If the host (Netlify/Cloudflare Pages) doesn't already strip dotfolders by default, `/.git/` would be crawlable and let someone reconstruct the full source history via tools like git-dumper. Added a defense-in-depth rule to `_redirects`:
```
/.git/*   /404.html   404!
```
This blocks the path at the routing layer regardless of what the host's default dotfile behavior is. Did not touch the actual `.git/` folder itself (that's the legitimate local repo, not something to delete).

**2. Title tag over length limit — FIXED.**
`hourly-rate-calculator/index.html`: title was 66 characters ("Real Hourly Rate Calculator (Australia) — Price Purchases in Hours"), over the 62-char practical truncation limit for Google SERPs. Shortened to "Real Hourly Rate Calculator (AU) — Price in Work Hours" (58 chars). Updated both `<title>` and `<meta name="twitter:title">` to match. Note: this page isn't part of the templated/generated set that `apply-seo.js` drives (no source in the build tool matched this exact title string), so the fix was applied directly to the static HTML. If this page ever gets re-templated by a build script, re-check this title doesn't regress.
