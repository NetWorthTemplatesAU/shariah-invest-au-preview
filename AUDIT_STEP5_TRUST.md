Date: 2026-09-30
Scope: `about/`, `methodology/`, `privacy/`, `index.html`, all `guides/`, all `learn/` and `learn-basics/` lessons, shared nav/footer template, favicon/logo references, branding, contact info.

Site was rebuilt (`node build.js` in `shariah-invest-au-build`) after the nav-template fix below to propagate it to all 357 pages. ## BREAKING (would embarrass the owner if a real visitor saw it)

### 1. Paid course mislabeled "Free" in the nav, on every single page of the site
- **Where:** Site-wide nav dropdown ("Learn" menu), which appears on all 357 pages (about, methodology, privacy, homepage, every guide, every stock page, every calculator, 404, etc.)
- **What:** The nav item for "Complete Financial Literacy" (the 46-lesson course that is going to be priced but currently renders free because the paywall isn't turned on yet) read **"Free course, 46 lessons"**. This flatly states the paid course is free, not "currently free" or "free for now" — a permanent claim.
- **Root cause:** `shariah-invest-au-build/lib/layout.js` built the nav description from `content/learn.json`'s `course.navDesc` field, which was hardcoded to `"Free course, 46 lessons"`.
- **Fix:** Edited `lib/layout.js` so the nav description for the paid course is generated independently of the content JSON's `navDesc` field — it now always renders as `"46 lessons"` (no free/paid claim at all, which is accurate regardless of paywall state). Ran `node build.js`, which stamped the corrected nav onto all 357 pages ("no drift — every page took the shared nav, footer and script"). Verified with a site-wide grep: zero remaining instances of "Free course, 46 lessons".
- **Note:** `content/learn.json`'s `course.navDesc` field itself still contains the wrong string. I did not edit it (content JSON is off-limits per instructions), but it is now dead code as far as the nav is concerned since layout.js no longer reads it for that field. **Flagged for the content-audit agent** to clean up or repurpose if they touch that file, so it doesn't mislead someone reading the JSON directly later.

### 2. Same "free course" claim repeated in 9 guide pages' cross-link callouts
- **Where:** `guides/aaoifi-vs-djim-msci-shariah-screening-standards/`, `computershare-margin-income-pre-revenue-miners/`, `halal-etfs-on-the-asx/`, `halal-smsf-australia/`, `is-my-super-halal/`, `islamic-will-australia/`, `paying-off-interest-based-debt/`, `sukuk-in-australia/`, `zakat-on-asx-shares/` — all had a "New to this?" callout linking into the paid course, ending "...as part of the free course."
- **What:** Same bug shape as #1 — asserts the paid 46-lesson course is free, permanently.
- **Fix:** These guide pages are hand-authored HTML (not generated by the build pipeline — `build.js` has no "Guides" generation step), so edited directly. Changed "as part of the free course" → "as part of the course" in all 9 files. Verified with grep: zero remaining instances.
